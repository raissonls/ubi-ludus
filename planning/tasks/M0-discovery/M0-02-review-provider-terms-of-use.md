# M0-02 · Review provider terms of use

**Milestone:** M0 Discovery spike (Nov 2-8) · **Priority:** Must · **Estimate:** 2 h

## Why

Some providers forbid republishing raw data on a public site (risk R2). Read the terms of the shortlisted providers before building anything on them.

## Definition of done

- [ ] Per provider: can derived data be published on a public site? Is attribution required? Is non-commercial use required?
- [ ] Decision recorded: which providers are allowed, and the minimum fields we publish.
- [ ] Fallback noted for competitions where republishing is not allowed (curated YAML calendars).
- [ ] PRD open question Q2 updated with the answer.
